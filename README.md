# Morphological phenotyping of live corals using 3D optical scanning

This protocol describes a workflow for phenotyping live corals by quantifying morphological traits from 3D models. It guides users through three main steps: (1) scanning live coral fragments or colonies with a structured-light scanner (EinScan SE V2, Shining 3D, China) and exporting the merged scans as meshes using EXScan S software (v3.1.4.3); (2) pre-processing and filtering the meshes in MeshLab (Visual Computing Lab, Italy); and (3) extracting 16 morphological descriptors using a computational pipeline of R scripts. The pipeline also calculates a composite morphological score to rank coral fragments based on their potential for successful restoration outplanting. The computational pipeline can also process 3D models generated by photogrammetry.

A Zenodo archive accompanying this repository is published at [10.5281/zenodo.24012515](https://doi.org/10.5281/zenodo.24012515).

## Repository structure

```
CoralMorphology/
├── docs/                      # Protocol for image acquisition and metrics documentation
├── scripts/                   # R scripts for computational pipeline
└── example/                   # Example pipeline outputs
```

## Documentation

| File | Purpose |
|---|---|
| `docs/protocol_image_acquisition_and_preprocessing.pdf` | Protocol for image acquisition, mesh pre-processing, and filtering |
| `docs/morphometrics_key.pdf` | Definition and calculation method for each of the 16 morphological descriptors |
| `scripts/README.md` | Installation, configuration, and instructions to run the computational pipeline to extract morphological descriptors |

## Pipeline scripts

| File | Purpose |
|---|---|
| `scripts/00_master_script_pipeline.R` | Runs the computational pipeline by calling scripts 01-05 in sequence |
| `scripts/01_pipeline_batch_check_format.R` | Checks each PLY file is readable and reports ASCII/binary format |
| `scripts/02_pipeline_batch_convert_to_ascii.R` | Converts binary PLY files to ASCII |
| `scripts/03_pipeline_batch_check_watertight.R` | Checks watertight status and sorts meshes |
| `scripts/04_pipeline_batch_analysis.R` | Calculates 16 morphological descriptors |
| `scripts/05_pipeline_merge_metadata.R` | Merges results with sample metadata |
| `scripts/06_pipeline_rank_fragments.R` | Ranks fragments by a composite score (runs independently from the master script) |
| `scripts/ShapeVariableFunctions.R` | Helper functions used by `04_pipeline_batch_analysis.R` |

## Requirements

**R packages:** `Rvcg`, `geometry`, `tidyverse`, `readxl`.

```r
install.packages(c("Rvcg", "geometry", "tidyverse", "readxl"))
```

**Python with `pymeshlab`:** Steps 3 and 3b shell out to Python to check watertight status and close holes.

```bash
pip install pymeshlab
```

`python3` (or `python`) must be reachable on your `PATH`; see `scripts/README.md` for environment-activation instructions.

## Example data

PLY meshes derived from structured-light scanner and from photogrammetry are available at [this link](https://cloud.uol.de/s/7N24Lws87YyQLCb) for a trial run of the pipeline. Running the computational pipeline on these meshes produces the example outputs in `example/`.
